# Block 31 — the owner's request of 2026-08-22, verbatim

Recorded here before any design, because a request that lives only in a
conversation dies at the next `/clear`. Block 30d had to recover the previous
list out of a transcript with a script; this file is the answer to that.

The text below is the owner's, unedited. Everything this block ships argues from
it, and where a design decision reads it one way rather than another, the spec
says so and quotes the sentence it is reading.

---

Implement the following adjustments in the existing application. Preserve the current architecture, permissions, security rules, pagination, filters, and existing behavior unless explicitly changed below.

## Organizations

1. In **Edit Organization**, add a function to move a **Station** from one Organization to another.
2. The operation must migrate the Station together with **all records and relationships associated with that Station** to the destination Organization.
3. Ensure there are no orphaned records or records that remain incorrectly associated with the previous Organization.

## Members

Page: `https://pulchatx.com/members`

1. In the grid, display only the **last 4 digits of the Member's phone number**.
2. Add the Member's **birthday (day and month only)** to the grid.
3. Adjust the date fields according to the selected **Date Filter**:

   * `Birthday`: **Birthdays from** and **Birthdays to** must use **Day/Month** only.
   * `Registered`: **Registered from** and **Registered to** must use **Day/Month/Year**.

## Promotions

Page: `https://pulchatx.com/promotions`

1. Add a **Refresh** button that reloads the current query while preserving the active filters.
2. Add a **Programme** column to the grid.
3. Show the Programme name when the Promotion has a Programme linked to it.

## Pickups

Page: `https://pulchatx.com/pickups`

1. Add a **Refresh** button that reloads the current query while preserving the active filters.
2. Rename the **View** button to **Member**. Do not change its current functionality.
3. Add a **pencil/edit icon button** to each applicable grid row.
4. Clicking the pencil must open a popup containing a summary of the prize/pickup information.
5. Move the following existing actions from the main grid/page into this popup:

   * **Return stock**
   * **Write off as lost**
6. Preserve the current behavior, validations, permissions, confirmation flow, and audit handling of these actions.

## Music Requests

Page: `https://pulchatx.com/music/requests`

1. Rename the **View** button to **Member**. Do not change its functionality.

## Participations

Page: `https://pulchatx.com/participations`

1. Rename the **Listener** button to **Member**. Do not change its functionality.

## Music Search

1. Exclude search results whose title/version identifies the track as **"Cover Version"**.
2. Apply this exclusion before displaying the results to the user.
